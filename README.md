# Jeopardy Data Analysis

A data analysis project built with Python and Pandas as part of Codecademy's Data and Programming Foundations for AI course.

## Technologies
- Python
- Pandas
- NumPy

## Project Tasks
- Filtering questions by keywords
- Cleaning and converting monetary values
- Counting unique answers
- Converting and analyzing dates
- Comparing questions across decades
- Exploring categories and rounds using crosstab

## What I Learned
Practical data manipulation, filtering, aggregation,
date handling, and exploratory data analysis.
